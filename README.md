# Speech Forge — 多场景发言稿锻造炉

> 把「场合 + 主题要点」锻造成一篇可直接上台的发言稿。
> 方法论源自依力老师《高效沟通领导能力》——一切沟通的底层能力是共情：**以对方的理解能力为基础，对方期待你怎么说，你就怎么输出。**

这是一个 [WorkBuddy](https://www.workbuddy.cn) Skill：安装后，只要对 AI 说"帮我写个答辩稿/面试自我介绍/竞选词"，它就会按对应场景的剧本生成结构清晰、逻辑严密、语言得体的发言稿，并智能调整语气、篇幅与重点。

## 支持的场景

| 场景 | 典型触发 | 核心打法 |
|---|---|---|
| 学术答辩 | 课程展示、大作业、毕业设计、竞赛答辩 | 答辩 = 80% 演讲 + 20% 说服 + 0% 辩论；最后一页放大纲 |
| 保研/考研复试 | 复试自我介绍、夏令营面试 | 项目只讲一个深的；"为什么选我们组"要具体 |
| 面试 | 社团招新、转专业、二次选拔、求职 | 岗位要什么，就证明有什么 |
| 汇报 | 组会、项目进展、工作总结 | 结论先行；坏消息带着方案说 |
| 演讲竞选 | 班委竞选、动员会、典礼发言 | 一句话法则：想清楚台下人想要什么，给他们什么 |
| 辩论 | 辩论稿、一辩立论、思政课辩论 | 说服观众，不说服对手 |
| 说服 | 拉赞助、给导师发邮件、谈资源 | 亮底牌、抬身价、给台阶、分步让步 |
| 拒绝 | 婉拒、推掉任务 | 直接拒绝，不解释三遍 |

## 核心方法论

**动笔前三问（共情预写）**——没想清楚不动笔：

1. 听众此刻的心态是什么？（默认答案：I don't give a shit——"跟我有什么关系"）
2. 听众对上台者的预期是什么？
3. 我要的结果，和听众的利益，在哪里接轨？

**演讲一句话法则**：好稿子往往有一句能被记住的话（文眼）。先写这句，再搭全文。

> 范本："如果今天我当选班长，全班所有同学，每一个人的事情，无论你们遇到什么事，每一个人的事情都是我的事情。"

**答辩公式**：80% 演讲 + 20% 说服 + 0% 辩论。只答不辩——先听懂、一句话直答、不绕弯、不沉默。除非对方陈述与事实有硬出入，不教老师做事。

**说服四步**（源自真实谈判实战）：真诚亮底牌 → 把对方捧到位给情绪价值 → 不逼决策主动给时间 → 分步加价显示诚意。

**篇幅速算**：中文发言约 240 字/分钟。3 分钟 ≈ 700 字，5 分钟 ≈ 1200 字，10 分钟 ≈ 2400 字。宁短勿长，超时是答辩最常见的死法。

## 使用方式

安装为 WorkBuddy 技能后，直接用自然语言触发：

```
帮我写一个 3 分钟的竞赛答辩稿，项目是基于机器视觉的智能分类垃圾桶，
听众是评委教授，重点讲算法创新
```

技能会输出四件东西：

1. **场景参数卡**：场景 / 听众 / 语气 / 篇幅 / 结构
2. **发言稿正文**：按场景骨架分节，标注时间与舞台提示（【停顿】【放慢】）
3. **场景附件**：答辩→预设问题库 + 一句话应答；面试→追问与应答；辩论→论点卡
4. **练稿提示**：含"写完必须朗读一遍"铁律

## 本地安装

```bash
# 克隆到用户级技能目录
git clone https://github.com/Secularity-9/speech-forge.git ~/.workbuddy/skills/speech-forge
```
